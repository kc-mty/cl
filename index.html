The IPO+S Concept Reference Sheet

Input Devices

Feeds data, sound, or user commands into the computer system (e.g., Mouse, Scanner, Webcam).

Processing / Memory

Executes instructions and holds active data temporarily for processing (e.g., CPU, RAM).

Output Devices

Displays, prints, or outputs processed data to human users (e.g., Monitor, Printer, Speaker).

Storage Devices

Saves files and programs permanently or semi-permanently for future use (e.g., SSD, Harddisk, Flash Drive).
